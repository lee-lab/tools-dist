# インストール手順（日本語）

English version: [user-guide.en.md](user-guide.en.md)

Windows 10 / 11（64bit）で動作します。**Python などを事前に用意する必要はありません。**

Apple Silicon の Mac では [8. macOS（Apple Silicon）](#8-macosapple-silicon) をご覧ください。1〜7 は Windows の手順です。

---

## 1. インストール

1. スタートメニューで `PowerShell` と入力し、**Windows PowerShell** を開きます。管理者として実行する必要はありません。

2. 次の 1 行をコピーして貼り付け、Enter キーを押します。

   ```powershell
   irm https://raw.githubusercontent.com/lee-lab/tools-dist/main/install.ps1 | iex
   ```

3. 画面の案内に従って、インストールするツールを選びます。

4. パスワードを聞かれたら、担当者からお伝えしたパスワードを入力します。
   入力中は画面に文字が表示されませんが、正しく入力されています。

5. `was installed successfully.` と表示されたら完了です。デスクトップにアイコンができています。

インストールには数分かかります。途中でウィンドウを閉じないでください。

> **画面表示は英語です。** 日本語話者以外の利用者にも同じ手順で使っていただくためです。

---

**VS Code 拡張（MMDAgent-EX）。** Visual Studio Code が入っていて、ターミナルで `code` コマンドが使える場合は、MMDAgent-EX のスクリプト編集を助ける拡張も自動で入ります。使えない場合は `code --install-extension "...\mmdagent-ex-lua.vsix"` のようなコマンドが表示されるので、VS Code を入れたあとにそのコマンドを実行してください。

## 2. 更新

**インストールと同じコマンドを、もう一度実行してください。**

```powershell
irm https://raw.githubusercontent.com/lee-lab/tools-dist/main/install.ps1 | iex
```

新しいバージョンがあれば更新されます。設定内容やダウンロード済みのデータはそのまま引き継がれますので、設定をやり直す必要はありません。

**更新のときもパスワードが必要です。** 控えを残しておいてください。

---

## 3. リリースチャネル

配布には 2 つのチャネルがあります。**特に案内が無ければ既定のチャネルをお使いください。**上のコマンドがそれにあたります。

| チャネル | 対象 |
|---|---|
| `beta`（既定） | 一般の利用者向け。通常はこちらをお使いください |
| `alpha` | 研究室の実験協力者向け。最新のビルドで、更新頻度が高めです |

alpha チャネルからインストール・更新する場合は、次の 1 行を実行してください。

```powershell
$env:LEELAB_CHANNEL = 'alpha'; irm https://raw.githubusercontent.com/lee-lab/tools-dist/main/install.ps1 | iex
```

同じコマンドをもう一度実行すると、**そのときのチャネルの中で**更新されます。何も付けないコマンドは beta のまま、alpha のコマンドは alpha のまま更新されます。

チャネルを切り替えるときは、切り替え先のコマンドを実行するだけです。現在どちらのチャネルが入っているかを表示したうえで、入れ替えてよいか確認を求めます。設定内容やダウンロード済みのデータは、通常の更新と同じように引き継がれます。

2 つのチャネルはバージョン番号が異なるため、alpha から beta に切り替えると古いバージョンが入ることがあります。これは想定どおりの動作です。

## 5. アンインストール

Windows の **設定 > アプリ > インストールされているアプリ** を開き、一覧からツール名を選んでアンインストールしてください。

## 6. うまくいかないときは

**アプリが起動しない／起動してすぐ消える**

スタートメニューの `Lee Lab` フォルダに **「（ツール名）(Diagnostic Mode)」** があれば、そちらから起動してください。黒い画面にエラー内容が表示されます。その画面をそのままコピーするか、写真に撮って担当者にお送りください。

この項目が無いツールもあります。その場合は、症状（どこまで表示されたか、エラーの文言）を担当者にお伝えください。

**「running scripts is disabled on this system」と表示される**

次のコマンドを実行してから、もう一度インストールをお試しください。

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

**インストールが途中で止まる／エラーで終わる**

ネットワークのプロキシやウイルス対策ソフトが通信を遮断している可能性があります。画面に表示されたエラーメッセージをそのままコピーして、担当者にお送りください。

**「64-bit Windows is required」と表示される**

64bit 版の Windows 10 / 11 が必要です。ARM 版の Windows には対応していません。

## 7. ディスク容量について

初回インストールでおよそ **4.5GB** を使用します。うち約 2.2GB は今後の更新を速くするための控えです。

ディスクの空きが少ない場合は、次のコマンドで控えを削除できます。次回の更新に時間がかかるようになるだけで、アプリの動作には影響しません。

```powershell
& "$env:USERPROFILE\.local\bin\uv.exe" cache clean
```

## 8. macOS（Apple Silicon）

一部のツールには macOS 版があります（現在は **MMDAgent-EX**）。インストーラには macOS 版のあるツールだけが表示されます。

**動作条件:** Apple Silicon（M1 以降）の Mac で、**macOS 15 以降**。Intel Mac には対応していません。事前に入れておくものはなく、管理者権限も要りません。

### インストール

1. **ターミナル**を開きます（Finder > アプリケーション > ユーティリティ > ターミナル。Spotlight で「ターミナル」と検索しても開けます）。

2. 次の 1 行をコピーして貼り付け、Return キーを押します。

   ```bash
   curl -fsSL https://raw.githubusercontent.com/lee-lab/tools-dist/main/install.sh | bash
   ```

3. パスワードを聞かれたら、担当者からお伝えしたパスワードを入力します。
   入力中は画面に文字が表示されませんが、正しく入力されています。

4. `was installed successfully.` と表示されたら完了です。

アプリは**ホームフォルダの「アプリケーション」フォルダ**（`~/Applications`。Finder で 移動 > ホーム を選び、「アプリケーション」を開く）に置かれます。Spotlight（Command + Space）でも探せます。

> **画面表示は英語です。** 日本語話者以外の利用者にも同じ手順で使っていただくためです。

### 初回起動

ほかのアプリと同じように開いてください。**セキュリティの警告は通常出ません。** インストーラが自分でファイルを取得するため、macOS は「インターネットからダウンロードしたもの」として扱いません。

それでも「開けません」「壊れているため開けません」と表示された場合は、**システム設定 > プライバシーとセキュリティ** を開いて下へスクロールし、そのアプリについての表示の横にある **「このまま開く」** を押してください。解決しない場合は、表示された文言をそのまま担当者にお知らせください。

### 更新

**インストールと同じコマンドを、もう一度実行してください。** コンテンツはそのまま引き継がれます。

### リリースチャネル

Windows と同じく、何も付けないコマンドは既定の `beta` チャネルです。`alpha` チャネルを使う場合は、`|` の後ろ、`bash` の直前に `LEELAB_CHANNEL=alpha` を付けます。

```bash
curl -fsSL https://raw.githubusercontent.com/lee-lab/tools-dist/main/install.sh | LEELAB_CHANNEL=alpha bash
```

同じコマンドを再実行すると、そのチャネルの中で更新されます。もう一方のチャネルのコマンドを実行すると、切り替えてよいか確認を求めます。

選んだチャネルにまだそのツールの macOS 版が無い場合は、その旨を表示して何も変更せずに終了します。

### アンインストール

ターミナルで次を実行します。

```bash
~/Library/Application\ Support/LeeLab/mmdagent-ex/uninstall.sh
```

アプリ本体、「アプリケーション」フォルダの項目、インストーラが入れた VS Code 拡張を削除します。**ホームフォルダの `MMDAgent-Contents` フォルダ（`~/MMDAgent-Contents`）にあるコンテンツは削除されません。**

### ファイルの置き場所

| もの | 場所 |
|---|---|
| アプリ本体 | `~/Library/Application Support/LeeLab/mmdagent-ex/` |
| 起動に使うアイコン | `~/Applications/MMDAgent-EX.app` |
| コンテンツ（MMDAgent-EX） | `~/MMDAgent-Contents`。更新でもアンインストールでも残ります |

**VS Code 拡張（MMDAgent-EX）。** Visual Studio Code が入っていれば、配布物に拡張が含まれている場合はそれも自動で入ります。入っていない場合は、あとで実行する `code --install-extension ...` のコマンドが表示されます。
