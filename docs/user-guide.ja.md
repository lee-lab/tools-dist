# インストール手順（日本語）

English version: [user-guide.en.md](user-guide.en.md)

Windows 10 / 11（64bit）で動作します。**Python などを事前に用意する必要はありません。**

---

## 1. インストール

1. スタートメニューで `PowerShell` と入力し、**Windows PowerShell** を開きます。管理者として実行する必要はありません。

2. 次の 1 行をコピーして貼り付け、Enter キーを押します。

   ```powershell
   irm https://raw.githubusercontent.com/lee-lab/tools-dist/main/install.ps1 | iex
   ```

3. 画面の案内に従って、インストールするツールを選びます。

4. パスワードを聞かれたら、担当者からお伝えしたパスワードを入力します。
   入力中は画面に文字が表示されませんが、正しく入力されています。

5. `was installed successfully.` と表示されたら完了です。デスクトップにアイコンができています。

インストールには数分かかります。途中でウィンドウを閉じないでください。

> **画面表示は英語です。** 日本語話者以外の利用者にも同じ手順で使っていただくためです。

---

## 2. 更新

**インストールと同じコマンドを、もう一度実行してください。**

```powershell
irm https://raw.githubusercontent.com/lee-lab/tools-dist/main/install.ps1 | iex
```

新しいバージョンがあれば更新されます。設定内容やダウンロード済みのデータはそのまま引き継がれますので、設定をやり直す必要はありません。

**更新のときもパスワードが必要です。** 控えを残しておいてください。

---

## 3. パスワードの取り扱い

- このツールは一般公開前のため、パスワードを知っている方だけがインストールできます
- **パスワードをプロジェクト外の方に渡さないでください**
- パスワードを忘れた場合、受け付けられない場合は、担当者にお問い合わせください

---

## 4. アンインストール

Windows の **設定 > アプリ > インストールされているアプリ** を開き、一覧からツール名を選んでアンインストールしてください。

---

## 5. うまくいかないときは

**アプリが起動しない／起動してすぐ消える**

スタートメニューの `Lee Lab` フォルダにある **「（ツール名）(Diagnostic Mode)」** から起動してください。黒い画面にエラー内容が表示されます。その画面をそのままコピーするか、写真に撮って担当者にお送りください。

**「running scripts is disabled on this system」と表示される**

次のコマンドを実行してから、もう一度インストールをお試しください。

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

**インストールが途中で止まる／エラーで終わる**

ネットワークのプロキシやウイルス対策ソフトが通信を遮断している可能性があります。画面に表示されたエラーメッセージをそのままコピーして、担当者にお送りください。

**「64-bit Windows is required」と表示される**

64bit 版の Windows 10 / 11 が必要です。ARM 版の Windows には対応していません。

---

## 6. ディスク容量について

初回インストールでおよそ **4.5GB** を使用します。うち約 2.2GB は今後の更新を速くするための控えです。

ディスクの空きが少ない場合は、次のコマンドで控えを削除できます。次回の更新に時間がかかるようになるだけで、アプリの動作には影響しません。

```powershell
& "$env:USERPROFILE\.local\bin\uv.exe" cache clean
```
